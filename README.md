# ICT WEEK 2026 — Home Page

Home page of the ICT Week Uzbekistan 2026 landing, built with Vue 3 and Vite
from the Figma design. Fully responsive: desktop (1440), tablet (720) and
mobile (390) breakpoints follow the corresponding Figma frames.

## Stack

- Vue 3 (`<script setup>`), Vite
- Plain scoped CSS, no UI libraries
- Manrope variable font (self-hosted via Fontsource)

## Getting started

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
npm run preview  # preview the production build
```
